# أردوينو أونو — نموذج ثلاثي الأبعاد تفاعلي

لوحة أردوينو أونو R3 مبنية **إجرائيًا بالكامل** بـ [three.js](https://threejs.org) (r180) — بلا نموذج GLB جاهز: كل مكوّن (الشريحة ATmega328P، منفذ USB، مقبس الطاقة، رؤوس الدبابيس، المذبذب، المصابيح، المكثفات) مبني من أشكال هندسية بأبعادها الحقيقية بالملّيمتر.

## المزايا

- **تدوير وتقريب** حر بالسحب وعجلة الفأرة (OrbitControls).
- **31 دبوسًا تفاعليًا**: مرّر فوق أي دبوس فتظهر حلقة تحديد وبطاقة عربية تشرح وظيفته.
- **تشغيل Blink**: مصباح L (الدبوس 13) يومض فعلًا على اللوحة.
- **عرض مفكّك**: المكوّنات ترتفع عن اللوحة لرؤية البنية.
- **بطاقة الشيفرة**: مثال Blink مع تلوين صيغي.
- متجاوب: تصميم مخصص للجوال، وواجهة عربية RTL.

## التشغيل محليًا

```bash
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

لا حاجة لأي خطوة بناء — الصفحة ثابتة بالكامل، وthree.js مضمّن محليًا في `vendor/`.

## البنية

```
index.html      الواجهة والـ import map
styles.css      ورقة المواصفات البصرية (RTL)
main.js         بناء المشهد والتفاعل
vendor/         three.js r180 + OrbitControls + RoomEnvironment + RoundedBoxGeometry
```

## الرخصة

الرمز متاح للاستخدام الحر. العلامات «Arduino» و«ATmega» ملك أصحابها.
